Privacy Policy

Last updated October 24, 2026

Who this covers

Molly Uploader is a private tool operated by Yoon Molly (Heeyoung Youn). It is used only for the operator’s own TikTok account. No data from other users is collected.

TikTok access

With the account owner’s authorization, the tool uses TikTok Login Kit to obtain an access token. That token is used with the user.info.basic and video.upload permissions so the operator can upload the operator’s own videos as drafts through the TikTok Content Posting API (inbox upload).

How tokens are stored

Access tokens are stored only on the operator’s private computer. They are never shared or sold.

Revoking access

The account owner can revoke access in TikTok settings. When access is revoked, the stored tokens are deleted.
