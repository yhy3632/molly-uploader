Molly Uploader

Molly Uploader is a private, non-commercial tool by Yoon Molly (Heeyoung Youn). It uploads the owner’s own videos to the owner’s own TikTok account as drafts, using the TikTok Content Posting API (inbox upload).

The tool is not offered to the public. Only the operator uses it, and only for the operator’s own TikTok account.
